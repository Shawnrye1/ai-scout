## SLIDE 5: How It Works (Technology)

# The Tech Stack

**Computer Vision Pipeline:**
- YOLOv8x for player/ball detection
- ByteTrack for multi-object tracking
- PaddleOCR for jersey number recognition
- Pose estimation for technique analysis

**AI Analysis:**
- Claude for natural language report generation
- Sport-specific evaluation frameworks
- Pattern recognition across games

**Infrastructure:**
- Modal.com for GPU compute (A10G)
- Cloudflare R2 for video storage
- Neon PostgreSQL with pgvector
